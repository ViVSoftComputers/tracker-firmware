# T1000-E Cached GPS Tracker

Custom Meshtastic firmware for the Seeed SenseCAP T1000-E.

## Included

- `firmware-tracker-t1000e.uf2` — prebuilt firmware
- `tracker_tool.py` — serial tracker utility
- `meshtastic-tracker-hook.patch` — upstream integration patch
- `src/modules/optional/CachedPhoneTracker/` — tracker module source

## Safety

Always back up the device configuration and factory firmware before flashing.
